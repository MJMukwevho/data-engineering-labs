# Data Engineering Labs

A hands-on repository for building and experimenting with modern data engineering patterns.

## Purpose
This repo is used to explore:
- Data ingestion patterns (batch & streaming)
- Distributed processing (Spark)
- Storage layers (Postgres, Data Lake)
- Containerized data workloads (Docker)

## Current Focus
- Java-based data ingestion
- Running Spark locally via Docker
- Building a modular data pipeline architecture

## Structure
- infrastructure/ → Docker, environment setup
- jobs/ → data processing jobs
- data/ → sample datasets

## Philosophy
Learn by building production-like systems locally before scaling to cloud environments (AWS/Azure).
